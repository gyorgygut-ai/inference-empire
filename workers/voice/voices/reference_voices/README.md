# Reference voices

Canonical reference speakers used by the **OpenVoice** voice-changer worker
(`handlers/voice_converter.py`) and the **Chatterbox** zero-shot TTS worker
(`handlers/chatterbox_tts.py`).

These are **committed to git** (the `.beamignore` exception
`!voices/reference_voices/*.wav` keeps them in the remote build context) so the
workers can load them at runtime without downloading anything in `on_start`.

| File      | Speaker | Source (iCloud vault) |
|-----------|---------|-----------------------|
| GutAI.wav | GutAI (assistant) | `gyuri.wav`  |
| ff.wav    | ff    | `ff.wav`     |
| bp.wav    | bp    | `peti.wav`   |

`manifest.json` is regenerated by `scripts/collect_voices.py` and lists each
voice id with its duration.

## Refreshing / adding voices

Place raw recordings in the iCloud `voice/` vault, then run:

```bash
python scripts/collect_voices.py
```

It applies `RENAME_MAP`, rejects files shorter than 4s, and rewrites
`manifest.json`. For best timbre transfer aim for **8–12s** of clean
single-speaker speech (minimum 4s; longer is tolerated but 10s+ is ideal).
